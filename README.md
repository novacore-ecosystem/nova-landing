# 🚀 Nova Landing [Demo Page]

⚠️ **IMPORTANT NOTE**
This repository serves strictly as a **Technical Prototype / Demo** designed for client preview and conceptual layout review. 
- The current codebase is **NOT** the final production product.
- Once the client approves the final UI/UX designs, the production system will be **completely rewritten from scratch** to ensure optimized performance, clean architecture, and strict adherence to the approved design.

---

## 🏗️ Tech Stack & Ecosystem

This project is built using **Next.js** and leverages the core ecosystem components to ensure standardization and rapid prototyping:

* **Framework:** Next.js
* **Core Ecosystem:** Built on top of **nova-core** architecture, utilizing core packages:
  * `@nova-core/frontend-foundation` - Global configurations, utilities, and base architecture.
  * `@nova-core/frontend-nextjs` - Pre-configured Next.js boilerplate and core setups.
* **UI Component Library:** **Material UI (MUI)**. 
  > *Note: MUI components are pre-wrapped and bundled within `@nova-core/frontend-nextjs` to maintain reusable UI tokens and design consistency across all ecosystem products.*

## 🎯 Purpose of this Repository
* **Layout Review:** To provide the client with a live preview of the structural layout and user flow.
* **Component Testing:** To test the responsiveness and compatibility of pre-wrapped MUI components.
* **Feedback Gathering:** To collect immediate client feedback for UI/UX iterations before official coding begins.

## 🔄 Next Steps in Development
1. **Client Sign-off:** Review layout/flows and finalize the visual designs (via Figma).
2. **Production Rebuild:** Initialize a fresh production repository. We will rewrite the codebase cleanly using the approved UI assets while keeping the same **nova-core** foundations.
